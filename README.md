# Fit Journal privacy policy

Public privacy policy for Fit Journal by AP Software Studio.

Support: apsoftwarestudio.support@gmail.com

The site contains an English index.html and policies in 13 languages.
Upload the contents of this folder to the root of the AP-Software-Studio/fit-journal-privacy repository.
Enable GitHub Pages under Settings > Pages: Deploy from a branch, main, / (root).

Expected site URL after deployment:
https://ap-software-studio.github.io/fit-journal-privacy/

When changing the policy, keep index.html in sync with en.html.
This folder contains only public policy files; no application code or signing keys.
